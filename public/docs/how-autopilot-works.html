How the autopilot actually decides

1

Gather — snapshot, positions, news

Before any scoring happens, the tick assembles everything it needs to reason about this symbol.

live snapshot (quotes + chains) greeks backfilled via Black-Scholes where missing open positions marked to current bid/ask relevant news, scored for direction
2

Exit check — runs first, runs always

Every open position is checked against stop-loss / take-profit before anything else — even if autopilot is currently disabled for this symbol.

if P&L on position ≤ −35% close · stop-loss
if P&L on position ≥ +60% close · take-profit
! There is no time-based exit. A position doesn't get closed just because expiration is approaching or the signal reversed — only these two P&L thresholds trigger a close.
3

Score the technicals

Seven indicators each cast a vote from −1 to +1, averaged and scaled to −100…+100.

RSI(14)
<30 → +1 · >70 → −1
MACD vs signal
above → +1 · below → −1
SMA20 vs SMA50
above → +1 · below → −1
Bollinger Bands
≤ lower → +1 · ≥ upper → −1
Stochastic %K/%D
<20 → +1 · >80 → −1
VWAP vs price
weight ±0.5
ADX/DI cross
only votes if ADX ≥ 25
techScore = average(votes) × 100
i StochRSI is computed but deliberately does not vote — it would double-count the same momentum idea as RSI.
4

Blend in news, then dampen for options quality

The technical score is combined with news sentiment, then discounted if the options themselves are unfavorable to trade right now.

directionalScore = techScore × 0.75 + newsScore × 0.25

Options-conditions penalty (0 to −100)

  • ATM IV rich → up to −50
  • Bid/ask spread wide → up to −30
  • Open interest thin → flat −20

Informational only — never affects the trade

  • News-vs-options divergence verdict
  • Options positioning bias (skew/OI read)
  • Volatility surface, gamma exposure
combinedScore = directionalScore × (1 + optionsScore / 200)
5

Trade gate — first blocking rule wins

Checked strictly in this order. The moment one blocks, everything below it is skipped.

01 today's P&L ≤ −15% of equity no trade · daily circuit-breaker
02 open positions ≥ 3 no trade · position cap
03 combinedScore −30 … +30 no trade · hold
04 combinedScore ≥ +30 buy call
04 combinedScore ≤ −30 buy put
6

Pick expiration & strike

Only reached once the gate above passes — direction is decided, now it needs an actual contract.

Expiration

  1. Keep expirations 3–10 days out with chain data
  2. Sort nearest first
  3. Skip any where daily theta burn > 6% of premium…
  4. …unless it's the last one left (never fully rejects)

Strike

  1. Target delta closest to 0.40
  2. Skip strikes with open interest < 100
  3. Skip strikes with spread > 10% of mark
  4. No delta data at all? → fall back to nearest 1%-OTM strike, unfiltered
! If delta data exists but every strike fails the OI/spread filters, autopilot does not fall back to the crude 1%-OTM rule — it just declines to trade.
7

Size the position

qty = floor( min(equity × 35%, cash) / (mid × 100) )

Capped at 35% of total equity per trade and by available cash. Rounds down to whole contracts — if that's zero, no trade.

Every tick ends one of three ways

No trade

Any gate blocks — hold signal, position cap, daily loss limit, no valid strike. lastDecision.reason records exactly which one.

Position opened

Gate passed, strike found, size ≥ 1 contract. Cash debited, trade logged as BUY.

Position closed

Stop-loss or take-profit hit on an existing position. Cash credited, trade logged as SELL with the reason.
